# Шаблон сайта для мастера маникюра

Демонстрационный сайт студии «Пудра» (выдуманная). Один файл `index.html`, без серверной части, публикуется на GitHub Pages.

## Что есть на сайте

- Первый экран с обещанием и блоком «Ближайшие окна».
- Услуги и цены, акция месяца.
- Календарь свободных окон: дата, время, выбор услуги, готовое сообщение мастеру (WhatsApp или копирование для Telegram).
- Галерея работ с фильтром. Работа открывается крупно, кнопка «Хочу такой дизайн» добавляет её в сообщение.
- Как записаться (3 шага), отзывы, частые вопросы, контакты, закреплённая кнопка на телефоне.
- Светлая и тёмная темы, телефон первым.

## Как настроить под клиента

Все настройки лежат в начале скрипта в `index.html`:

| Что | Где |
|---|---|
| Telegram и WhatsApp | `CFG.tg`, `CFG.wa` |
| Рабочие дни и время приёма | `WORK_DAYS`, `TIMES` |
| Занятые окна | `BUSY`, при этом `CFG.demo` поставить `false` |
| Выходные | `DAYS_OFF` |
| Услуги и цены | `SERVICES` |
| Работы | `WORKS` (для фото добавить `src:'photos/имя.jpg'`) |
| Название, адрес, график, акция, отзывы, вопросы | прямо в HTML |
| Цвета | переменные в начале `<style>` (светлая и тёмная версии) |

## Публикация

1. Новый репозиторий `template-manicure`, загрузить `index.html` и `README.md`.
2. Settings → Pages → ветка `main`, папка `/ (root)`.

## Ограничения

- Это витрина. Запись не происходит на самом сайте: клиент отправляет сообщение, мастер подтверждает.
- Занятость окон задаётся вручную в `BUSY` (по подписке обновляет владелец шаблона). В демо она выдумана автоматически.
- Перед публикацией проверить: в коде нет паролей и ключей, в фото нет геометок (EXIF), на изображения есть права.
