# Шаблон сайта для мастера маникюра

## Что есть на сайте

- Первый экран с обещанием и блоком «Ближайшие окна».
- Услуги и цены, акция месяца.
- Календарь свободных окон: дата, время, выбор услуги, готовое сообщение мастеру (WhatsApp или копирование для Telegram).
- Галерея работ с фильтром. Работа открывается крупно, кнопка «Хочу такой дизайн» добавляет её в сообщение.
- Как записаться (3 шага), отзывы, частые вопросы, контакты, закреплённая кнопка на телефоне.
- Светлая и тёмная темы, телефон первым.

С сайтом можно ознакомиться по ссылке - https://zlaysobaka.github.io/pudra/
